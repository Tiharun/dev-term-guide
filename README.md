# 개발 용어 설정집

개발 용어를 움직이는 그림과 도식으로 보여 주는 한국어 용어 사전이에요. 용어를 몰라도 눈에 보이는 증상으로 찾을 수 있고, 카드마다 Claude에게 그대로 보낼 수 있는 말하기 예문이 있어요.

## 주요 기능

- **증상으로 찾기:** 무엇이 이상한지 고르면 그 현상의 이름을 알려 줘요.
- **움직이는 그림:** 용어마다 실제로 움직이는 예시나 도식이 있어요.
- **말하기 예문:** 용어를 정확하게 쓰는 문장을 바로 복사할 수 있어요.
- **검색·즐겨찾기·외운 용어 표시:** 로그인 없이 쓰고, 기록은 브라우저에 저장돼요. 파일로 내보내고 불러올 수도 있어요.

개발 기본, 디자인, 프론트엔드, 백엔드, 보안, AI 등 18개 분류에 용어 1,800여 개가 들어 있어요.

## 사용법

[사이트](https://tiharun.github.io/dev-term-guide/)에서 바로 쓸 수 있어요. 기록은 브라우저에 저장되고, 다른 PC나 새 브라우저로는 핀 화면의 Pin·외움 목록으로 옮길 수 있어요.

[`index.html`](index.html)을 내려받아 브라우저로 열면 돼요. 설치할 것이 없고 인터넷 없이도 동작해요.
